# AI-Assisted Java Development

Companion resources for practical lessons on **Claude Code, IntelliJ IDEA, Java, Spring Boot, Maven, Git, and AI-assisted development**.

Find the lesson you're following below. Each lesson page contains commands and prompts you can copy into your own terminal or Claude Code session. Lessons use descriptive folders, **not sequence numbers**, so the publishing order can change.

## How to use these resources

Open the lesson README while watching the video. Follow its steps in order, and copy the commands or prompts where indicated. Review any proposed file changes and verify command output on your own machine. Some Claude Code screens and options may differ by version and account.

## A note about examples

These READMEs are viewer handouts, not instructor scripts or claims that a command or AI-generated change succeeded on your machine. No credentials, API keys, or private machine-specific data should be committed.
